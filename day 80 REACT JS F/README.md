# 🧩 Pokémon Explorer — React.js (Work in Progress)

A **React.js web application** that fetches and displays Pokémon data using the **PokéAPI**.
This project is currently **under active development** and will evolve into a **full multi-page website**.

---

## 🚧 Project Status

**In Progress 🚀**

At the moment, the project focuses on:
- API integration
- State management
- Dynamic data loading

Upcoming updates will expand this into a complete, multi-page React application.

---

## 🔗 Data Source

- **PokéAPI** — https://pokeapi.co/

---

## 🚀 Current Features

- Fetches Pokémon data from a real public API
- Uses **Axios** for HTTP requests
- Implements paginated data loading
- Dynamic rendering of Pokémon cards
- Basic infinite scroll logic
- Handles loading state and error cases

---

## 🛠️ Tech Stack

- **React.js**
- **JavaScript (ES6+)**
- **Axios**
- **PokéAPI**
- **HTML5**
- **CSS / Tailwind CSS (UI in progress)**
